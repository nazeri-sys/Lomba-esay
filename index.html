Panduan GitHub

Cara Upload Kode Ini ke GitHub

Ikuti perintah terminal di bawah ini untuk menyimpan kode website ini ke repository GitHub Anda.

1 Inisialisasi Git & Commit File

Buka terminal di folder project Anda, lalu jalankan perintah berikut:

git init
git add .
git commit -m "feat: initial commit website lomba esai"

2 Hubungkan ke Repository GitHub

Buat repository baru di GitHub Anda, lalu sambungkan URL remote:

git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPOSITORY.git

3 Push ke GitHub

Kirimkan seluruh kode ke branch utama GitHub:

git push -u origin main
